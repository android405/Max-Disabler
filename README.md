## Описание
Расширение наглядно позволяет показать, что у Вас не открывается и/или неправильно отображается Веб-версия мессенджера.

## Установка расширения

### Chrome, Edge, Chromium-GOST
Перейдите к списку расширений <a href="chrome://extensions">chrome://extensions</a>, нажмите на кнопку Загрузить распакованное расширение, после чего выберите папку с раширением.

#### Установка под Yandex.Browser
<p>Откройте скачанный .crx файл через браузер, либо перенесите .crx файл расширения на страницу: <a href="browser://tune">browser://tune</a></p>
<b>Примечание для пользователей Yandex.Browser: </b>каждый запуск браузера будет сопровождаться высплывающим окном о том, что расширение небезопасно и оно было отключено, это связано с тем, что оно было установленно не через магазин расширений, а вручную.

### Mozilla Firefox
Расширение доступно по <a href="https://addons.mozilla.org/addon/max-disabler/">ссылке</a> в каталоге аддонов Mozilla</a>

## Как работает расширение?
Расширение изменяет код отображаемой страницы в зависимости от выставленных параметров

## Что умеет расширение?
<ol>
<li>Выдавать "белую" страницу;</li>
<li>Убирать QR-код для входа;</li>
<li>Убирать форму входа.</li>
</ol>
<strike><li>Делать неактивным поле ввода номера телефона</strike> (удалено)</li>
